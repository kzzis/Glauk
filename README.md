## かんがえかた

**記法を消さない。** 見出しも太字もリンクも、打った文字はそこに残したまま、見た目だけを整えます。
書いたものと表示されるものがずれないので、カーソルを置けばいつでも原文が見えます。

**黙って保存する。** 打ち終わってしばらくすると自動で保存します。
インジケータもトーストも出しません。**失敗したときだけ**知らせます。

**画面は一枚。** タブはありません。リンクを辿ると同じ画面が入れ替わり、⌘[ で戻ります。
ノートツリー(⌘\\)もクイックスイッチャー(⌘O)も、出したいときだけ出して畳めます。

## いま動くもの

`[[リンク]]` はローカルフォルダを走査して解決します。通信もプラグインも要りません。
記法は Obsidian 互換なので、既存の vault をそのまま開けます。

- 見出し・太字・リスト・チェックボックス・引用・コールアウト・テーブル・数式・タグ・脚注
- コードのシンタックスハイライト(diff は差分として色分け)
- `[[` の補完、リンク移動、未作成リンクからのその場作成
- 自動保存

グローバルショートカットでの呼び出しと、AI が書き換えた行が「インクのにじみ」のように
浮かんで消える表示も、これから。

## つくり

解析は **Zig**、UI は **Swift + AppKit**(TextKit 1)。

Zig は「どこからどこまでが何の記法か」という範囲の一覧だけを返します。
Swift はそれを見て属性を付けるだけで、テキストストレージには手を入れません。
だから原文が保たれ、日本語入力の変換中でも壊れません。

```sh
cd core && zig build              # コアを先に
open macos/Glauk/Glauk.xcodeproj
```

Zig 0.15.2 と Xcode が要ります。テストは `cd core && zig test src/root.zig`。

## はじめかた

右上のボタンでノートを置くフォルダを指定すると、`[[` にそのノートが出ます。
指定しなくても、単一ファイルのエディタとして動きます。
